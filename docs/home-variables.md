# 首页 IP 变量

| 变量 | 显示 |
| --- | --- |
| `{ip}` | 当前轮播 IP，每 10 秒切换一个地址 |
| `{primary_ip}` | 固定主 IPv4 地址 |

与 OLED 一样，读取 Core 状态 `network.ip` 和 `network.ipv4_addresses`。主 IP 优先，其余地址按 Core 的顺序排列（包括备用静态地址），去除空项和重复项。地址列表改变时从首项重新计时；只有一个地址则保持显示。旧 Core 未提供地址列表时继续显示单个 IP；没有可用地址时显示 `--`。

首页与网页预览使用同一轮播规则；各自从加载地址列表时开始计时。变量表显示当前值，可点击复制变量名。新增文本组件使用 `{primary_ip}` 可固定显示主地址，已有 `{ip}` 组件自动启用轮播。
