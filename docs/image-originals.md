# 图片素材与显示区域

静态图片、GIF 和 WebP 上传时，经已认证的 `remote/media/image` 流式接口原样保存到屏幕服务的 `media/` 目录。素材的 `original` 保存文件引用、原始宽高及字节数；`frames` 为供设备绘制的 RGB565 小图或动画帧，原文件不进入设置 JSON 或 D-Bus。素材库显示原始尺寸，静态图片预览与背景显示区域编辑使用原图。

背景 `{x,y,zoom}` 使用可移动范围内的百分比及 0.1–4 倍缩放（10%–400%，100% 为铺满）。网页从原图裁切并以高质量采样生成面板尺寸的 RGB565 背景；保存重开继续使用原文件。只缓存当前选中原图，旧异步渲染结果在更换素材、撤销或重置后不再写回。渲染完成前不可保存，异步编辑合并为一个撤销步骤。

历史仅含 RGB565 帧的素材兼容保留，但无法从缩略图恢复原始细节；需要重新上传原文件。保存素材库后回收已删除素材的原文件，未保存的上传保留一天以支持其他设计器草稿。

首页卡片默认底色为 `#11192099`（60% 不透明度）。网页与 PocketJS 都保留 `#RRGGBBAA` 的 alpha，屏幕最终合成为 RGB565。

缩小后超出图片的区域使用页面背景色，半透明颜色在设备黑底上合成。缩小的图片可在留白内拖动，背景色修改会重新生成相同显示区域。
