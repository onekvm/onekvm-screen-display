# 列表滚动合成

列表和整页切换都由 Linux framebuffer 宿主合成缓存像素。不要在每个动画帧重新执行 guest JS、布局和文字光栅化，也不要将两个已裁剪的可见窗口直接拼接：后者会在露出区域跳行，并在结束时突然替换选中颜色。

内置 Settings、App 列表、服务／安全 App 和初始化列表在旋钮改变选中项时提交 `appScrollTransition`：

```text
direction:distance:y:viewportHeight:node:parent:targetOffset:contentHeight
```

- `direction=1` 表示内容向上移动；`targetOffset` 是正的绝对内容偏移。
- `distance=0` 仍是有效请求，用于只改变高亮、不移动视口的渐变。
- `node` 是完整列表条带，`parent` 是其原容器；这些列表均是容器的唯一子节点。
- 宿主在本次 guest 状态提交后，将条带临时挂到独立离屏 root，绘制完整内容，再恢复原树和位移。期间不执行 guest JS，因此不改变 Vue mirror 或命中测试结构。
- 同一 node 且像素尺寸不变时，复用已缓存的列表，只重绘变化的行。node 或尺寸变化时整表重绘。
- 目标视口直接裁剪刚绘制的完整图层，只对固定栏单独光栅化；不要把可见列表再次绘制一遍。动画帧以整数 RGB565 混合选中颜色，不逐像素执行浮点插值。
- 内置列表的短颜色动画先在 native UI 中完成；只有宿主展示插值，避免将尚未完成的 CSS 颜色缓存为最终状态。离屏条带高度限制为 8192 px，避免错误请求造成无限分配。
- 动画期间只按绝对内容坐标裁剪缓存。旧画面与目标图层在相同内容坐标上混合，文字和行边界不发生重影错位；固定栏不随列表移动。
- 新输入从最后实际显示的偏移接续，不从上次目标接续，也不先推进一个未呈现的动画帧。多格输入和反向输入共用此路径。
- 同进程 guest 直接调用公开 D-Bus 接口所用的 `Shared` 后端；不可为每个输入／状态字段循环调用自己的 D-Bus 服务。设置仍是独立 bundle 和 guest，对外 D-Bus 接口不变，写配置也只执行一次。
- 设置页的 IP、SSID 和网卡列表只在网络相关页面刷新；这些 getter 缓存失效后会同步查询 D-Bus，不应阻塞屏幕、时区等列表的输入首帧。

服务与安全 App 共用 `src/shell/ScrollList.tsx`，所有行放在同一连续条带内，
刷新位于末尾，页头保持固定。离开列表进入详情或编辑时，立即停用旧列表的手势与滚动提交。

旧的四字段请求继续使用对齐后的双视口合成作为兼容回退。旧宿主会忽略附加字段，因此服务和内置 guest 应一起交付，才能使用完整图层方案。

初始化进程复用同一个完整列表、整页和抽屉合成器；步骤／网络子页切换优先于同帧的列表请求。静态列表不保持 guest 热循环，网络信息只在进入相关页面和每秒刷新；欢迎轮播、异步提交和错误处理仍保留。抽屉选项在退出动画的墙钟时间到达后应用，不按 guest 帧数等待。

## 触摸与旋钮

初始化同时支持旋钮选中与触摸直接拖动、点击，不能按 Pro 型号禁用任一输入。触摸打断旋钮缓存动画时，宿主通过只读瞬时值 `appScrollPosition=node:offset` 提供最后实际显示的位置，列表核对 node 后接续；不得跳到先前的目标位置。空的松手帧也必须立即交付，不能等缓存动画完成。

正常 App 的底部白条上滑一次返回主屏；左边缘右滑向 App 发送 Back，设置子页逐级返回，根页面或不处理 Back 的叶子 App 返回主屏。系统手势先判断主方向，再接管并显式 CANCEL guest 接触，避免误点或吞掉左边缘的纵向列表滚动。短滑、反向撤回和普通轻点不导航。

初始化未完成时不启用底部 Home 手势，也不允许手势绕过初始化；左边缘右滑依次关闭错误、抽屉、键盘或退回上一页，忙碌提交时不导航。

验收必须覆盖单格、多格、动画途中反向、仅高亮变化和两端边界；同时核对中间帧的空间连续性及最终高亮。FPS 或仅检查起止截图不足以证明过渡正确。Pro 的原生屏幕为验收目标，NanoKVM PCIe 的独立 OLED 不安装此 framebuffer 包。

触摸回归还需覆盖动画中接管、拖动后松手、再次使用旋钮、边缘纵向拖动、白条上滑、右滑关闭键盘／抽屉及初始化 Home 无操作。本地 guest 模拟覆盖 240×240 和 Pro 320×172；模拟通过不等于触摸硬件或实机帧率验收。
